This repository contains only the already-tested static runtime and its original build manifest. The development repository remains private. No rebuild was performed for deployment.

Tap fixed mirrors to rotate them, connect the receiver, undo or confirm reset, and unlock all five levels. Completion progress and settings are stored on this browser; unfinished sessions are not saved. Loaded sessions can play offline; offline reopening is not supported.

Mobile validation is pending: touch/cancel/scroll/orientation, safe areas, audio, and real-device performance. This preview is not Sprint 1 product acceptance or a formal release.
